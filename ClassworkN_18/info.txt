/*
1*) GET - получить ресурс
2) HEAD - то же самое что и get, но без тела - только заголовок
3*) POST - создать новую запись
4*) PUT - Заменить запись на новую целиком
5) PATCH - частично обновить
6*) DELETE - удалить запись
7) OPTION - Узнать допустимые методы
*/
-----------------------------------
/*
[
	{1, Alise, 22}
	{2, James, 23}
	{3, Arnold, 21}
]
	REST API, значит чтобы достать Alice
	GET /users/1 -> {1, Alise, 22}
	PUT    /users/1 -> request body: {"id": 1,
									  "name": Alise Smith,
									  "age": 23}
	PATCH  /users/1 -> request body: {"age":23}
*/
-----------------------------------
/*
	Статус коды:
	1хх - информация
	2хх - успех
		200 - ОК
		201 - Created
		202 - Accepted
		204 - Контента нет (В ответ на Delete)
	3хх - Перенаправление
		301 - Moved Permanently - Ресурс переехал
		304 - Not Modified - Кеш актуален
	4хх - Ошибка клиента
		400 - Bad request
		401 - не авторизовано
		403 - Forbidden - отказ в доступе от сервера
		404 - Not found
		405 - Метод не разрешен
		409 - Конфликт данных
		422 - Валидация не прошла
		429 - Слишком много запросов
	5хх - Ошибка сервера
		500 - Неожиданная ошибка
		502 - Bad Gateway
		503 - Сервис в настоящее время недоступен (перегружен/перезагружается)
*/
